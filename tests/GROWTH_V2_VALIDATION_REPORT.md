1. 신규 Lv1 캐릭터에 시작 10슬롯 선택권이 등록되지 않는 문제를 수정.

3. 동일한 경지 돌파 시험 ID를 반복해 성공으로 바꿔 쓰는 우회 차단.
4. 기존 삭제된 캐릭터의 GitHub 파일을 계속 읽도록 되어 있던 README·GAME_RULES·CHAT_CAMPAIGN_PROTOCOL·PLAY_FROM_CHAT·CHARACTER_CREATION·CHARACTER_GROWTH의 오래된 경로 제거.
