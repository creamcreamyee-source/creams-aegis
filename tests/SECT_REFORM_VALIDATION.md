## 2. 150개 구조 조합의 범위

- 기존 3종족 유형: 인간 / 야성 감각형 / 기운 감응형
- 기존 5가지 무학 운용 태그: 압박·연계 / 유도·반격 / 기동·교란 / 정밀·견제 / 축적·변환
- 선천 재능 등급 5: 범재 / 수재 / 천재 / 괴물 / 초월
- 시작 경로 2: 문파 입교 / 무문파 독행
- 직교 합계: 3×5×5×2 = **150개 구조 시나리오** (문파별 실명/체질/무공/체계 공식 미확정이라 **실제 캐릭터 빌드 150개 전투 검증이 아님**).
- 앞으로는 150개의 구조 조합에 실제 입교 조건/심법 품질·숙련·능력치·무공·전투 카드와 세계 상태를 공급해야 한다.

## 3. 실제 테스트 이전에 막아야 할 결함

| 상황 | 기대 결과 |
|---|---|
| 초월·괴물 재능으로 문파 입문 | 고급 심법 전수·지도 선택이 실제로 표시됨. 조건 충족 후 운용; 자동 대성 없음 |
| 초월 재능 무문파 독행 | 시작 기연/구결에 대한 유효한 경로 제공. 숨겨진 RNG만으로 처리하지 않음 |
| 범재 독행자 | 필수 10슬롯과 레벨 보상 보존. 장기적 최상위 경지 도달은 막지 않음 |
| 심법 두 개 활성화 시도 | 활성 핵심 슬롯 1개라는 규칙 위반 차단. 소지·독서 기록은 가능 |
| 문파를 떠난 인물 | 과거 무공 수련·전수 이력 보존, 사문/현재 소속/인연 각각 갱신 |
| 무림맹 소속으로 옮김 | 출신 사문 유지. 맹 가입만으로 남궁/소림/화산 비기 자동 개방 불가 |
| 깨달음의 고급 심법 획득 | 비급 보유와 사용 가능 여부 구분, 수련·경지·XP 자동 상승 금지 |

| 새 자원 공식과 구 세이브 상한 충돌 | 자동 완치/조작 없이 호환성 오류 명시 후 적용 보류 |
| 다른 작품의 특정 비기명/정사 복제 | 독자적인 구결·전승 사유·인물로 대체 후 배포 |

## 4. 미검증 범위 — 완료로 표기하면 안 됨

- 기술 피해식·내력 자원·심법 품질 효율·재능별 수련 시간·주화입마 확률과 실제 이익/손실.
- 3종족×문파/독행×재능×심법 전수 조건을 **실제 엔진으로 전수 실행**하는 검사.
- 보스·다수전·위치·엄폐·상성·수련 중단·크림이 자율 전투 시뮬레이션.

- v10 **원본 전체**와의 조문 단위 대조(현재 참조는 WEB_ENGINE_RULES.md라는 2차 정리).
- 고유 세력명·비급명·설정의 출판물과의 최종 중복/유사성 검토.
