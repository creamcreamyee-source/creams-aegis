# CREAM’S AEGIS — A안 실전 플레이 우선형 검증 보고서

- 날짜: 2026-11-02
- 대상: **Lv1~3 신규 캐릭터 생성 → 입교 장면 → 심법 수련 게이트 → 기본 전투 → 성장/세이브의 분리 운영**
- 판정: **최소 실행 경로 PASS (실험 룰 적용 시)**.
- **최종 수치 정본 및 전체 전투 밸런스: 미승인 / 미검증**. D-038~D-043의 확정 내용은 변경하지 않음.

## 2. 밸런스 결과 — 제한된 범위

다음은 초기 시드 전투에서 관찰된 **실험적 범위** (각 시나리오 11경로, 경로당 200회, 최종 패치 전후 전체 회귀 검사에 의한 점검)이다.

| 적 상황 | 경로 간 대략적 승률 범위 | 해석 |
|---|---:|---|
| 무장 호위 적 1인 | 43~70% | 일반 실전의 기초 난도. 격차가 남아 조정 필요 |
| 정예 무인 1인 | 4~12% | Lv1 강제 보스전에 부적합 |
| 적 2인 | 16~44% | 위험한 다수전; 호위/준비/도주 경로 제공 |
| 원거리 공격 적 | 33~73% | 궁술·진법·빙공과 근접 무학의 상황별 강점이 드러남 |
| 민간인 호위 | 약 22~53% | 보호 무학의 효용이 있지만 후속 조정 필요 |

- 별도 쉬운 적 카드(훈련용 대련/일반 강도)는 더 높은 승률을 보이며 **도입용**으로 분리했다. 시제품 적 난도는 최종 밸런스 정본이 아니다.
- **주사위 의도성 확인:** 실제 d20 난수 사용, 자연 1 실패/20 성공, 샘플 전투 추적에서 자연 1/20 모두 관찰.
- **알려진 차이:** 계열별 편차가 남아 있다. 숫자만 완전히 맞추기보다 전투 환경별 역할과 최소 생존 능력을 함께 개선해야 한다.
- 적은 고도화된 장기 전략 AI가 아니라 지정된 공격 목표·사거리·속박 상태로 동작한다. 동료 전체 자율 AI/보스 페이즈는 별도 과제.

## 3. 핵심 버그 수정

1. MP 계열이 SP가 고갈되었을 때 엉뚱한 기술 사용으로 중단되던 부분 → `legalActions`와 예측 비용 검사.
2. 주도권이 적에게 있는데 플레이어가 먼저 이동하던 부분 → 적 행동 우선 정정.
3. 여러 적이 플레이어를 공격할 때 반응 기술을 한 턴에 여러 번 사용하는 부분 → 라운드당 1회 제한.
4. MP로 구동되는 반응기에 SP가 잘못 소비되던 부분 → 실제 반응 카드 비용 사용.
5. 두 번째 전투에서 **현재 HP/SP/MP가 최대치로 변하는 오류** → 현재값과 최대값 분리.
6. 이미 배우지 않은 초식이나 비급 접근만 한 인물이 전용 무공을 즉시 쓰던 문제 → 활성 심법·실제 배운 기술 ID로 사용 승인.
7. 새 캐릭터의 Lv1 10슬롯 선택 대기와 옛 세이브 자동 복원이 섞이지 않도록 별도 신규 세션 생성과 등록부 공백 가드 적용.
8. 한 적에게 교섭/퇴각을 무한 반복해서 승리하는 행동 → 교섭·퇴각 각 1회 시도 제한.

## 4. 세이브·정본 안전성

- GitHub의 현재 `CAMPAIGN_REGISTRY.json`: 활성 세션 ID null, 세션 목록 [].
- 이번 테스트의 가상 인물과 시험 전투는 JS 메모리에서만 생성했으며 **GitHub에 실제 신규 캐릭터 파일을 만들지 않았다**.
- 새 캐릭터의 사용자 확인 전 세션을 정식 기록으로 저장하지 않는 `confirmedByPlayer` 게이트가 동작했다.
- 게임의 세부 수치와 11개 경로의 기술 성능은 **실험값**; 새로운 D-044 확정 결정 없이 기존 D-038~D-043을 유지.
- GitHub는 실제 도구 호출로 저장/재조회하는 구조. 온라인 동기화·백그라운드 자동저장을 약속하지 않는다.

## 5. 플레이를 시작할 수 있는 범위 및 개방 과제

**가능:** 새 캐릭터 선택, 입문 첫 사건, 괴물/초월의 상급·비전 심법 첫 관문 혜택, 심법을 실제 배우는 사건, 기본 공격 및 적 1~3명 판정, 임시 문파 무공 A1/A2·보법·반응, 비살상/교섭/퇴각, 첫 XP·성장 보상 대기, 주요 사건 GitHub 저장.

**남음:** 승인된 수치로 장기 밸런스, Lv4~12 상위 무공 실제 구현, 종족별 공식 고유 능력, 크림이 완전한 동료 AI, 여러 NPC 동시 행동 및 전술, 심법 상충/주화입마/부상 후유증의 확정 공식, 사용자 동의가 필요한 최종 문파명/계급/세계사.

**결론:** A안의 목적에 해당하는 **짧은 정식 신무협 캠페인 도입은 실험 수치 표기를 전제로 가능**. 전체 게임 완성 또는 장기 성장 수치 최종 승인이라고 표현해서는 안 된다.
