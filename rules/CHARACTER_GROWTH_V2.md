## 1. 여섯 개의 독립 성장 축

| 축 | 무엇이 성장하는가 | 무엇을 자동 부여하면 안 되는가 |
|---|---|---|
| 레벨/XP | 성과 경험, Lv1~12의 기술·특기 **선택권** | 경지 돌파, 자원 완전 회복 |
| 선천 재능 | 태생적 학습·기연·지도 특혜 (범재·수재·천재·괴물·초월) | XP만으로 재능 등급 상승 |
| 심법 품질/숙련 | 구결 접근, 정식 전수, 실제 운용, 소성·대성 | 비급 획득 즉시 심법 대성 |
| 내공·기혈 | 내공 축적, 운기 성질, 안정, 잔맥 영향 | 무한 HP/MP/SP 증가 |
| 무공·초식 | 기술 입문·연계·비기·경공·진법 전문화 | 문파 가입만으로 비기 일괄 해금 |
| 무협 경지 | 별도 깨달음·돌파 조건·시련 | 레벨에 따른 자동 승급 |

문파 공헌/사부 신뢰/교단 직책은 **제7의 사회적 성장 원장**이며 개인 전투 스탯과 분리한다.

## 3. 실제 레벨업 트랜잭션

1. 사건의 목표 ID와 XP 보상 사유를 확정한다. 같은 목표를 전투·협상으로 중복 해결해도 XP 이중 지급 금지.
2. 전투 중 XP 발생 시 전투가 끝날 때까지 반영을 지연한다.
3. 이전 XP → 증가량 → 새 XP로 누적 레벨 계산, 새 레벨 보상만 pendingGrowth에 추가한다.
4. 플레이어가 기술·패시브·특기를 직접 선택한다. 현재 심법·사문 전수권·무학/체질·비급 구결의 합법적 획득 경로를 확인한다.
5. 승인된 수치나 기술 효과를 **별도 이벤트**로 적용한 후에만 보상을 appliedGrowth로 이동한다.
6. 레벨업만으로 HP/MP/SP 완전회복·경지 돌파·비전 심법 자동 대성 금지.
7. GitHub 원장/서사/상태에 저장, 재조회로 검증. 실패하면 부분 저장이라고 고지한다.

예: 270XP 캐릭터가 XP230을 받으면 Lv3(500XP), 액티브 선택권이 열린다. 이전 Lv2 패시브의 지급 근거가 없으면 이를 자동 중복 지급하지 않고 확인 대기시킨다.

## 4. 심법 수련과 무공 전수

- 심법 상태: 비급의 존재 인지 → 구결 접근/보유 → 적법 전수 → 첫 관문 → 운기 입문 → 소성 → 대성 → 원만 (후반 단계 명칭과 정확한 조건은 **제안**).
- 수련 이벤트에는 스승/기연 ID, 심법/초식 ID, 사승 허락, 수행 시간, 실제 판정/서사적 증거, 기존 숙련, 변화한 숙련, 대가와 인물 반응을 기록한다.
- 전수자가 없는 무문파 독행은 기연·비급 복원·자기 깨달음을 정식 출처로 인정한다.
- 괴물은 상급, 초월은 비전 **첫 심공 관문**의 조기 접근권을 갖는 상세 후보. 더 빠른 XP 배율이나 매 레벨 능력치 보너스는 **미승인**.
- Lv10 심법 진화는 성장 분기 선택권이다. 기존 심법의 운기 진화나 새로운 비전 탐구를 열되 자동 대성·경지 상승은 불허한다.
- 교단 호법의 지도나 문중 비전 심법에 접근했다는 사실과 그 심법을 실제 사용할 수 있다는 것은 다르다.

## 5. 경지와 레벨은 독립

기존 v10 2차 정리의 **일반적 대응 레벨**: 삼류 1~2 / 이류 3~4 / 일류 5~6 / 절정 7~8 / 초절정 9 / 화경 10 / 현경 11 / 생사경·검선지경 12.

이것은 권장 수준 참고표이며 레벨업에 따른 실제 경지 변경 규칙이 아니다. 경지 돌파 조건·실패/재도전·지식·기혈·내공·시련은 따로 정해야 한다.

## 6. 신규 캐릭터 성장 원장

- 새 인물의 상태는 `CAMPAIGN_REGISTRY.json`에 등록된 별도 `sessions/<NEW_ID>.json` 파일의 `growth` 필드로 관리한다.
- `earnedRewards[]`: 지급 완료 XP의 objective ID와 rewardKey.
- `queuedAwards[]`: 전투 중 획득했으나 종료 후 반영할 XP.
- `pendingGrowth[]`: 레벨 도달로 열렸으나 아직 사용자가 고르지 않은 보상.
- `appliedGrowth[]`: 승인된 기술/능력치 반영 증거가 있는 보상.
- `cultivation`: 심법 구결·숙련/공력/경지/돌파를 기록(수치 공식 미확정 시 UNKNOWN).
- `trainingEvents[]`: 심법·초식 수련의 실제 결과와 시간·교사·대가.

현재는 **저장된 캐릭터가 0명**이다. 이미 삭제한 옛 시연 캐릭터의 Lv/XP/초식/심법을 신규 세이브에 복원하지 않는다.
