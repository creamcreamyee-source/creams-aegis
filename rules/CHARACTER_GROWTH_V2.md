## 3. 캐릭터 생성과 27 Point Buy

- STR(근력), DEX(민첩), CON(건강), INT(지능), WIS(지혜), CHA(매력).
- 시작 각 능력치 8~15 / 정확히 27점 사용 / 능력 수정치 `floor((score-10)/2)`.
- 비용표 (기존 기준): `8→0, 9→1, 10→2, 11→3, 12→4, 13→5, 14→7, 15→9`.
- 3종족의 공식 명칭·기능은 현재 정본상 일부 OPEN이므로 사문 이름에서 종족을 자동 추론하지 않는다.
- 선천 재능은 Point Buy의 능력치와 독립 선택 항목. 높은 재능을 임의로 능력치 +2로 바꾸지 않는다.
- 재능의 실제 획득법(자유 선택/시험/확률)은 아직 OPEN이므로 **플레이어 선택 확정 이전 자동 추첨 금지**.
- 사문/세가/교단/세외/독행과 무학 분야는 분리. 문파를 이탈해도 배운 기술의 증거와 사회적 평판이 보존됨.

### 신무협 2.0 캐릭터 생성 순서

1. 배경·종족 후보·선천 재능·사문 또는 무문파를 고른다.
2. 27PB를 직접 배분해 검산한다.
3. 해당 전승 경로의 심법 비급·첫 관문(품질과 **접근권**만)을 확인한다.
4. 핵심 심법 1 + 초식2 + 보법/추가행동1 + 반응1 + 패시브3 + 고유재능2를 후보로 정하고, Lv1 보상을 pending으로 등록.
5. 수련 전수 사건 후 실제 배운 것만 활성화하고, 새 세이브를 GitHub에 저장·재조회한다.
6. 미승인 HP/MP/SP 수치나 기술 효과를 적용할 때는 명시적으로 **EXPERIMENTAL**을 표시한다.

## 4. 자원 증가 공식 후보 [EXPERIMENTAL ONLY]

기존 `proposals/STATS_SKILLS_V1.md`의 초안에서 가져와 신규 전승 경로에 대해 **수학적 범위만 검사**한 비교 모델이다.

- 숙련 보정(proficiency): Lv1~4 +2 / Lv5~8 +3 / Lv9~12 +4.
- 최대 HP 후보: `20 + 2×CON 수정치 + 6×(Lv-1)`.
- 최대 SP 후보: `10 + 2×WIS 수정치 + 2×(Lv-1)`.
- 최대 MP 후보: `10 + 2×INT 수정치 + 2×(Lv-1)`.
- DEF 기본값 후보: `10 + DEX 수정치`.
- 예시 `STR10 / DEX14 / CON14 / INT10 / WIS13 / CHA12` 27PB → Lv2 최대 HP30/SP14/MP12.
- 검증 범위: 합법적인 27PB 배분 **12,282개 × 12레벨 = 147,384개 계산**에서 HP18~90, SP8~36, MP8~36 범위; 음수/비단조 오류 없음.
- **의미:** 수식은 계산 가능. 그러나 전투의 적정 라운드, 기혈·궁술·심법 상성, 장기전 자원은 전혀 검증된 것이 아니므로 정본 공식으로 확정 불가.

## 5. 심법 숙련과 선천 재능 [EXPERIMENTAL]

심법의 '품질'은 기초·정통·상급·비전·절세, '숙련'은 미운용·입문·소성·대성·원만을 임시 명칭으로 사용한다. 각각 실제 전투 효과는 아직 별도 후보.

수련 표식(trained marks) 예시: **실제 게임시간 60분 이상인 의미 있는 수련 장면에 1개**, 큰 깨달음 근거가 있으면 추가 1개, 하루 최대 2개. 이벤트 ID 중복은 차단한다.

숙련 관문의 기본 누적 표식 기준 후보:

| 다음 숙련 | 기본 누적 표식 |
|---|---:|
| 입문 | 1 |
| 소성 | 4 |
| 대성 | 10 |
| 원만 | 20 |

- 실제 요구량은 `ceil(기본 누적 표식 × 심법 품질 난도 × 재능별 수련 효율)`, 최소 1개.
- 품질 난도 후보: 기초1.0 / 정통1.2 / 상급1.5 / 비전2.0 / 절세3.0.
- 재능별 노력 계수 후보: 범재1.0 / 수재0.9 / 천재0.8 / 괴물0.65 / 초월0.5.
- 예시: **기초·범재** 입문/소성/대성/원만 `1/4/10/20`개, **상급·괴물** `1/4/10/20`개, **비전·초월** `1/4/10/20`개. **절세·초월** `2/6/15/30`개.
- **수련 표식이 충분하더라도 자동 승급하지 않는다.** 별도의 깨달음·호법/사부의 평가·운기 성공 등의 이벤트 ID가 있어야 입문→소성 등 한 단계만 증가한다.
- 같은 비급을 중복 획득하거나 재능을 바꿔 수련 시간 단축을 우회하는 행위는 차단한다.
- 심법 활성 슬롯은 1개. 첫 관문 접근만으로 활성 불가; 실제 입문 운기 이후 활성.
- 재능별 계수와 수련 시간은 사용자의 별도 수치 승인 전까지 **실험안**이며 통계·체감 밸런스 검증이 필요하다.

## 6. 무공 수련·문파 기연

- 기술마다 `techniqueId`, 실제 사승/비급/기연 출처, 선행 심법, 자격 시험, 수련 이벤트를 기록.
- Lv3 액티브·Lv9 상위무공·Lv11 궁극기는 **획득 보상 선택권**일 뿐 문파의 금전비기를 바로 독점하는 것이 아니다.
- 같은 기술을 두 번 배우면 새 기술 슬롯이나 XP를 중복 지급하지 않는다.
- 무문파도 Lv2/3/4 등의 보상을 정규적으로 획득해야 한다. 대신 기연·은거고수·독학의 획득 원장이 필요.
- 소림·화산·남궁·북해·신교는 각자의 자원/상성을 가진 심법·초식을 제공하되, 실제 이름/효과는 현재 게임 데이터의 PROPOSED 목록에서만 임시 선택 가능.

## 7. 경지 돌파: 레벨과 독립 [CONFIRMED STRUCTURE]

일반적인 Lv 대응(v10 2차 기준): 삼류1~2 / 이류3~4 / 일류5~6 / 절정7~8 / 초절정9 / 화경10 / 현경11 / 생사경·검선지경12.

**실제 돌파는 별도 선택과 독립 사건:**
1. 적합한 심법·초식 수련 이력 / 기혈 안정 / 경지 시험·생사의 경험 등 준비 근거를 확보한다.
2. 독립적인 돌파 목표와 판정/서사 근거, 예상 비용을 사전 제시한다.
3. 플레이어가 돌파를 시도한다. 결과·비용·내상·시간을 별도 이벤트로 기록한다.
4. 성공한 경우에만 한 단계 진입. 실패해도 즉시 사망/영구 부상 확정은 하지 않고 기존 경지 유지와 실제 대가를 기록한다.
5. 같은 판정 ID를 재활용한 돌파 중복 지급 금지. 구체 DC/주화입마/재도전 공식은 OPEN이다.

## 8. XP와 10막 20장의 분량 계획 [EXPERIMENTAL]

- 20장 최종 보상인 Lv12 특기를 결말 전에 활용할 수 있도록 XP 이벤트의 배치 시간은 시나리오 테스트로 조절해야 한다.

## 9. 실제 세이브/엔진과 저장 원장

- `CAMPAIGN_REGISTRY.json`: 현재 세션 목록 (현재 0명).
- `sessions/<NEW_ID>.json`: 실제 생성된 새 캐릭터 상태.
- `sessions/<NEW_ID>_LEDGER.md`: 수련·NPC·목표·경지 등 서사 원장.
- `growth.earnedRewards[]`: 목표별 XP 지급 이력.
- `growth.queuedAwards[]`: 전투 종료 후 반영할 XP.
- `growth.pendingGrowth[]`: Lv1 시작 10슬롯 및 새 레벨 미선택 보상.
- `growth.appliedGrowth[]`: 승인된 효과가 적용된 후 근거 이벤트를 담은 영수증.
- `growth.cultivation.arts[]`: 비급 소지·전수·숙련 및 훈련 표식.
- `growth.cultivation.trainingEvents[]` / `masteryEvents[]` / `breakthroughEvents[]`: 모든 성장의 출처.
- 도구 실제 쓰기 → SHA 재조회 성공을 확인하기 전에는 자동 저장 완료를 선언하지 않는다.

## 10. 테스트와 확정 경계

**현재 검증한 사실:**
- 새 캐릭터 11문파/독행 × 5재능 × 3종족 유형 = 165 조합 생성 가능.

**아직 통과하지 않은 부분:**
- 실제 전투·보스·다수전·크림이 자율 참여·20장 XP 보상 실제 분배.
- 각 심법·기술의 진짜 사거리/행동권/피해/상태이상/내공 소모 밸런스.
- 재능별 수련 표식 속도·기연 접근권의 플레이 체감·경지 실패 비용.
- v10 원본 전체 조문 감사와 캐릭터 생성 3종족의 구체 명칭·고유 능력 확정.

**운영 결론:** 정본 D-042~D-043의 성장 **구조와 로직**을 실전 표준으로 사용한다. 새 수치·효과는 `[EXPERIMENT]` 표기 및 별도 승인 전 정본이 아니다.
