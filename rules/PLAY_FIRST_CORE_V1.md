## 1. 시작 캐릭터와 세계 접근

1. 새 인물의 이름·출신·종족 유형(인간/야성 감각형/기운 감응형의 **임시 타입**)·재능(범재/수재/천재/괴물/초월)·입교/세가/교단/세외/독행을 선택한다.
2. 6능력치를 **27 Point Buy**로 검증한다. 기존 5직업은 강제 선택하지 않는다. 선택한 무학 전승에서 기초 심법과 초식 후보를 가져온다.
3. 괴물은 **상급 심공 첫 관문**, 초월은 **비전급 첫 관문**을 입문·독행 초반에 실제로 마주하는 구조(실험 등급표). 이는 **완전 운기·심공 대성·경지 돌파가 아님**.
4. `session_bootstrap_v1.js`로 Lv1·XP0·시작 10슬롯 선택권을 가진 **신규 세션 자료**를 생성한다. 사용자 명시 선택 `confirmedByPlayer`가 없으면 생성 거절. 이 함수는 GitHub에 파일을 쓰지 않는다.
5. 실제 GitHub에 `sessions/<NEW_ID>.json`·`sessions/<NEW_ID>_LEDGER.md`·등록부를 쓰고 **재조회 검증 완료 후** 정식 캠페인이 생성됐다고 보고한다. 동기화는 수동 도구 호출이며 백그라운드 자동 아님.
6. 시작 장면은 `SECT_INTRO_SCENES_V1.json`의 해당 경로 입문 장면에서 사용자에게 의미 있는 선택을 제공한다. 미리 옛 캐릭터의 역사·NPC·스탯을 넣지 않는다.

## 2. 입문 심법과 초식 획득 — 핵심 차이

**처음부터 비급에 접근한 것과 실제 초식을 쓸 수 있는 상태는 다르다.**

`MANUSCRIPT_ACCESS → TRAINING_EVENT → FIRST_MASTERY_EVENT → ACTIVE_HEART → ACTUAL_TECHNIQUE_TRAINING`

- 입문 첫 장면에서는 **비급/구결 접근과 높은 재능의 특혜**가 보장된다.
- 운기 성공·사부의 실제 지도/기연·훈련 시간/깨달음 기록이 쌓여야 심법을 활성화한다. `cultivation_reducer.js`는 접근만 한 비급의 활성화를 거부한다.
- 기초 초식 A1/A2·보법/추가행동·반응기 또한 **전수·수련 사건으로 실제 습득**해야 한다. Lv.1 슬롯 10개가 예약되어 있다는 이유만으로 자동 습득하지 않는다.
- **미수련 상태에서도** 맨손 기초공격, 방어, 호흡 회복, 교섭, 퇴각을 할 수 있다. 미습득 전용 기술은 `campaign_battle_gate_v1.js`가 거절한다.
- 종족/문파/독행에 따른 스승·위계·전수권, 첫 선택의 갈등이 수련 가능성을 변화시키되 주요 목표 자체는 공유한다.
- 높은 재능은 초기 심법 **접근·지도**의 실제 우대를 제공하지만 Lv/XP를 건너뛰게 하지는 않는다.

## 3. 전투 한 라운드 [EXPERIMENT]

- **주도권:** 전투 시작 시 플레이어 d20+DEX 수정치 대 적 d20+2. 먼저 행동할 쪽을 결정. 동률은 플레이어 선공.
- **행동권:** 한 라운드에 이동(거리 구역 최대 1칸), 주행동 1회, 추가행동 최대 1회, 반응 최대 1회.
- **사거리:** 거리 구역 0/1/2. 근접 공격은 같은 구역만, 중거리는 최대 2구역까지.
- **주행동:** 기본공격 BASIC / 배운 초식 A1·A2 / GUARD(방어) / RECOVER(SP·MP 일부 회복) / RETREAT(퇴각) / PARLEY(교섭 가능한 상대에게 1회).
- **판정:** 플레이어 공격 d20 + 2(임시 숙련) + 대응 능력 수정치 vs 적 DEF. 자연 1은 실패, 자연 20은 성공. 주사위 결과·DC·비용을 사건에 남김.
- **시작 피해:** 공격 적중 시 1d6 + 대응 능력 수정치(음수라면 최소 피해 1), A1·A2의 조건부 효과는 각 문파 고유 토큰/상태/자원으로 별도 처리.
- **자원:** A1은 보통 해당 무공의 SP 또는 MP 2, A2는 3, 추가행동은 SP 1, 반응은 실제 무공 카드의 SP/MP 2. 최초 기술 비용 1 감소는 시작 패시브 P2의 실험 동작. 자원이 부족한 경우 사전에 합법적인 행동만 제시.
- **반응:** 적 여러 명이 한 라운드에 공격하더라도 플레이어 반응은 한 번뿐이다. MP 기반 심법의 반응에는 MP를 사용한다.
- **방어:** 능력치에 따른 DEF, GUARD, 호위/반격 계열의 실제 효과. HP가 0이면 전투는 패배지만 **상처/포박/죽음은 장면의 사전 정의된 후속 결과**로 판단하며 주인공의 즉사를 임의 확정하지 않는다.
- **휴식:** 전투 중 RECOVER는 SP 최대 3·MP 최대 2를 각각 상한 이내로 회복한다(주행동 소비, 방어 보정 +1). 전투 종료 시 자원이 자동 완전 회복되지 않는다.
- **퇴각:** DEX 기반 d20 판정, 성공이면 `escaped`, 실패하면 상대가 대응. 한 번의 전투에서 동일 퇴각 시도 무한 반복 금지.
- **교섭:** 실제 협상 가능한 적에게 CHA 기반 d20, 성공 시 `truce`, 실패하면 상대 행동. 해당 전투에서 계속 교섭을 재시도해 확률만 반복하지 못한다.
- **승리 이외의 결말:** `player / enemies / escaped / truce`를 구분. 교섭/회피/비살상 성공은 목표 해결 기록 및 후속 분기에 반영.

> **주의:** 현재 전투 코드는 기초 전투 시뮬레이터다. 완전한 지형·엄폐 전술·행동권 인터럽트·중상/주화입마·다수 동료의 자율 AI까지 구현됐다는 뜻이 아니다. 크림이의 행동은 D-기존 자율 원칙을 지키며 허위 자동 피해를 추가하지 않는다.

## 4. 11개 경로의 전투 선택 차이

| 수련 계열 | 시작 토큰·행동 | 특징적 상황 | 선택의 대가 |
|---|---|---|---|
| 소림 | 수호·호위 | 동료를 보호하고 비살상 제압 | 단독 폭발 화력에는 제약 |
| 무당 | 유도·균형 | 상대 공세를 흘리고 반격 | 공격을 읽어야 효율이 올라감 |
| 화산 | 검세·연계 | 초식 연결 후 검세 소모 | 연계를 끊으면 다시 축적 |
| 남궁 | 압박·검세 | 방어 돌파·강맹한 초식 | 짧은 공격에 자원 집중 |
| 팽가 | 중도·중량 | 근접 다수·범위 타격 | 추격·장거리에서 불리 |
| 당문 | 암기·혈맥 | 약화·혈도·비살상 | 제압에 준비 과정 필요 |
| 제갈 | 진식·공명 | 진법 준비 후 발동·범위 | 준비에 MP·시간 사용 |
| 천마 | 환류·위험 | 기운 회수 후 폭발 공격 | 자가 기혈 부담 |
| 북해 | 음한·한맥 | 한기를 누적해 행동 제약 | 내공 소모·느린 마무리 |
| 조선 궁술 | 조준·사거리 | 원거리 집중 견제 | 근접 압박·엄폐에 제약 |
| 독행 | 관찰·응변 | 상황에 맞춘 초식 조합 | 개별 문파 비기의 직접 전수 부재 |

위 전술 효과와 단계별 수치는 **초기 실험 구현**이며, 정본으로 승인된 실제 사문별 독문무공이 아니다.

## 5. 시작 적의 난도와 스토리 진행

`STARTER_ENCOUNTERS_V1.json`은 처음 배운 무공을 보여주는 훈련상대, 일반 강도, 무장 호위, 원거리 위협, 동료 호위, 나중에 도전할 정예 적을 구분한다.

- 입교 첫 대련은 **비살상·실패해도 배울 점이 있는 수련**으로 구성한다.
- Lv1 정예전 승률이 낮게 나타났으므로 **정예 결투/보스전을 초반에 강제하지 않는다**.
- 전투를 피한 플레이어도 교섭·호위·조사·기연·사승 공헌으로 공정한 경험치를 얻을 수 있도록 XP 목표를 설정한다. 같은 목표에서 중복 XP 지급 금지.
- 성공/실패 여부와 별개로 NPC의 독립적인 행동 및 자신의 지식 범위, 기억·대가·세계 상태를 시간 원장에 보존한다.

## 6. 성장과 자원 장기 보존

- 경험치·성장보상: `growth_reducer.js`. 레벨업 보상은 `pendingGrowth`에 등록, 실제 적용은 사용자 선택/효과 근거 후에만.
- 심법·경지: `cultivation_reducer.js`. 높은 재능·좋은 비급·많은 수련표식이 곧바로 자동 대성/경지 돌파가 되지는 않는다.
- **현재 HP/SP/MP와 최대 HP/SP/MP는 별도.** 다음 전투에 남은 HP를 최대 HP로 덮어 쓰는 오류 금지.
- 기존 `GROWTH_EXPERIMENT_V1.json`의 시작 HP/SP/MP 공식 등은 [EXPERIMENT]. 새 캐릭터 생성시 해당 실험 룰 버전을 고정해 세이브에 기록하고, 플레이 중 임의로 밸런스를 바꾸려면 명시적 마이그레이션 및 감사가 필요.
- 게임에서 획득한 비급·기연·심공·무공은 모두 출처와 전수/수련을 기록하며, NPC가 모르는 기밀은 지식 원장에서 자동 누설하지 않는다.

## 7. GitHub 체크포인트 프로토콜

1. 대화 시작 시 `MASTER_CANON.md` / `DECISION_LOG.md` / `CAMPAIGN_REGISTRY.json` 및 활성 세션 상태/서사 장부를 **실제 재조회**.
2. 사용자 선택 처리 전에 선택 ID·기술/자원 합법성·NPC의 실제 지식 확인.
3. 소설형 내러티브를 제공하고 선택→결과→주사위/자원/관계/시간 변화 및 비가역 비용을 계산.
4. 중요 선택/첫 심법 수련/무공 습득/전투 및 챕터 종료 시 상태·서사 원장에 동일한 이벤트 ID 기록, 각 파일 쓰기 및 **재조회 검증**.
5. 부분 실패/동기화 실패를 성공으로 보고하지 않는다. 다른 대화에서 재개할 때에는 마지막 검증 성공한 체크포인트만 확정한다.
6. 정본 세계관 개정은 사용자 승인 후 별도 D-044+ 결정으로 기록하며, 이 문서는 **새 정본 결정을 발생시키지 않는다**.
