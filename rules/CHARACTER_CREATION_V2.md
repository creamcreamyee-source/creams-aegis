# CREAM’S AEGIS — 문파 선택·독행자 캐릭터 생성 v2.0

- 작성: 2026-11-02
- 상태: **D-038~D-041 확정 구조를 구현하기 위한 OPERATING DESIGN; 세부 수치/진영 이름/특혜 등급은 PROPOSED**
- 주의: 현재 REBIRTH 세이브는 전투 규칙의 초안이나 선택한 사문·심법을 기록하지 않았다. 과거를 임의로 작성하지 않는다.

## 1. 캐릭터의 정체성을 분리한다

1. identity: 이름, 연령, 성격, 목표 (실제 사용자 인적사항 불필요)
2. race/heritage: 기존 3종족 유형·독립 혈통(D-026~030), 플레이어가 선택
3. stats: STR/DEX/CON/INT/WIS/CHA 27 Point Buy, 모두 8~15에서 배정 (기존 기준)
4. talent: 범재/수재/천재/괴물/초월(v10 2차 출처), 선정 방식 OPEN
5. origin: 평민/문중/방랑/군영/신교 유년 등 개인의 과거 배경
6. startingPath: SECT / FAMILY / CULT / WANDERER / FRONTIER (종류는 후보)
7. sectMembership: 사문·현재 신분·사부·공헌·사문 금기, 무문파라면 null
8. currentAffiliation: 무림맹/혈랑/녹림/직속타격대 등 별도 조직, 없을 수 있음
9. activeHeartArt: 현재 운용하는 1개의 핵심 심법, 구결 출처와 숙련
10. martialDisciplines: 검/권/도/궁/경공/암기/진법/술법/독 등 획득한 전문 분야
11. skillLoadout: 핵심 심법1/액티브2/추가행동1/반응1/패시브3/고유재능2 = 10슬롯
12. companions, world, quests: NPC의 실제 지식과 선택의 결과 보존

**무림맹 가입 ≠ 사문 변경**이며 **소림에서 권법을 배웠다는 것 ≠ 권사라는 고정 직업**.
문파 입문·파문·객경·비밀 사승·독학은 관계와 전수권, 이름값에 영향을 주되 스탯을 자동 지우지 않는다.

## 2. 캐릭터 생성 화면/채팅 순서 (1회 선택 단계)

1. 자기 배경·전투에서 가장 하고 싶은 일(검·권·도·궁·빙공·독·진법 등) 고르기
2. 재능과 타고난 체질·제약 확인 (결정 방식 미확정)
3. 심법을 배울 통로 선택: 문파 입교 / 세가 수련 / 마교 교단 / 북해·조선·북방 세외 / 독행
4. 사문과 전수권의 차이를 보여주고, 입문 제안서(사부·계율·공헌·위험)를 확인
5. 첫 심법의 완전성·운용 요건·수련 정도를 확인하고 활성 심법 1개 선택
6. 27PB 능력치를 배분하고 10슬롯의 합법적인 기술/재능 후보를 선택
7. 선택 확인(변경 시 현재 정보 유지) → 원장 반영 → 실제 프롤로그/첫 사건 시작

선택을 반복해서 묻게 되는 것을 막기 위해 현재 선택 가능한 3~5개 핵심 경로를 설명하고, 원하면 세부 문파 목록을 펼쳐 볼 수 있도록 한다. 특정 문파를 고르지 않아도 시작 가능하다.

## 3. 사문과 심법에 따른 초반 차별화의 최소 규칙

- 동일한 종족·Lv·능력치라도 **소림 입교자 vs 북해 독행자**는 배운 첫 심법·교사·입문 시험·첫 사건 대응이 다르다.
- 괴물/초월은 첫 전수/기연에서 고급 심공이 실제로 제공되는 **수련 결과**를 봐야 한다. 단지 설명 문장만 달라지면 실패.
- 범재도 어렵지만 비전/절세 비급을 얻을 기회가 있으며, 무공의 기초 숙련과 정보·인연이 다른 방식으로 보상받는다.
- 게임의 첫 심법이 더 높아도 Lv.2→Lv.3 XP를 생략하지 않으며, 자동 대성/경지 돌파도 발생하지 않는다.
- 문파가 없어도 초식2·심법1 등 기존 열 슬롯은 유지. 무문파의 초식은 서당 사부/낭인 스승/기연/독학 등 유효한 기원을 붙여야 한다.

## 4. 문파·독행의 두 예시 (세부 명칭/등급은 아직 제안)

A. [괴물 / 소림 / 권·장] → 장로의 조기 지도, 상급 심법 첫 단계를 배움, 금강 외공의 시험. 사문을 수호하고 계율을 어기지 않아야 고급 금전 무공 후보에 접근. 근접 전투와 병자 보호에 서로 다른 강점.

B. [초월 / 무문파 / 북해 빙공] → 한기가 흐르는 동굴 유산의 단서를 초기 서사에서 발견, 파편 비급으로 비전 심공의 첫 관문을 열 수 있음. 한기 제어가 불완전하므로 수련이 필요하고, 빙공 실전기술은 별도 습득. 문파에 들지 않았기 때문에 자유로운 연구가 가능하지만 도움을 받기 어려움.

C. [범재 / 남궁 검객] → 기초 검기 심법을 착실히 익힘. 세가의 직전 비전을 자동으로 받지 못하지만 강호 임무로 검법의 빈틈을 발견하고 사승을 변화시킬 수 있음.

D. [천재 / 제갈세가 / 진법] → 정통 운기와 기초 진법을 배우며 상급 공명 심법의 해독 시험 기회 제공. 제갈세가의 정치/진법 비밀을 무조건 알고 있다고 가정하지 않음.

## 5. REBIRTH 기존 세이브의 신규 스키마

해당 캠페인 캐릭터는 프롤로그 완료 상태:
- Lv.2 / 270 XP / HP23(초안 상한30) / SP8(상한14) / MP12(상한12)
- 이미 일어난 사건: 아이 보호, 하온 기억 장애 악화, 환자의 증언, 여섯 번째 서명란의 탁본, 크림이 추적 성공, 연묵 목소리에 대한 기억 상실
- 미기록: 종족, 출신, 선천 재능, 직업/무학 전문성, 심법, 27PB 배분, 10슬롯

마이그레이션 원칙:
1. 기존 캐릭터의 인적/수련 항목은 **PENDING_CREATION**, 플레이어가 선택하기 전 진위를 만들어내지 않는다.
2. 프롤로그 완료 세이브의 HP/MP/SP/XP/아이템/선택/시간/관계는 **그대로 유지**.
3. 새 규칙의 최대 자원 공식과 기존 상한이 맞지 않으면 자동 보정·완치·재생성하지 않고 **호환 불일치**를 표시해 별도 결정.
4. 플레이어가 사문을 선택해도 연묵이 그 문파의 심법을 전수했다고 소급 확정하지 않는다. 최초 전수는 플레이어가 선택·목격한 장면에서 기록한다.
5. 레벨2 패시브 보상 미선택 상태는 pendingGrowth로 보존. 사용자 선택 후 1회만 적용하며 200 XP를 다시 지급하지 않음.
6. 선택 전에 무작위로 재능·문파·신공·장비·내력·경지를 주거나 장면을 진행하지 않는다.

## 6. 수련·심법·재능 상태 저장 필드 [PROPOSED]

race, heritage, talentTier, talentOrigin, innateConstitution, originBackground,
martialDisciplines, sectLineage, sectMembership, sectRank, sectTrust,
currentAffiliation, masterRelationships, vows, obligations,
knownManuscripts, teachingPermissions, activeHeartArtId,
heartArtMastery, innerPowerReserve, circulationState, innerPowerNature,
stabilityState, realm, breakthroughConditions, pendingGrowth,
skillLoadout, techniqueProvenance, trainingEvents, irreversibleConsequences.

명시적 사용자 선택 없는 필드는 UNKNOWN/OPEN/null. 재능이 높아도 공식 전투 수치가 미정이면 특혜의 실제 상태만 기록하고 전투 능력치 계산을 꾸며 내지 않는다.

## 7. 공식 승인 전 남은 결정

- 시작 문파 목록·분파·세가의 실명 확정.
- 재능을 선택할지, 확률로 결정할지, 특정 서사에서 결정할지.
- 재능별 심법 시작 등급, 전수 보장 방식, 훈련 시간·효율 및 불이익.
- 심법 등급·숙련의 전투/비전투 실제 효과, MP/SP와 내공의 관계.
- 캐릭터 전수 이력과 레벨2 패시브 보상 확정.
