## 1. 무학의 중심 [STRUCTURAL DECISION]

선천 재능·체질 → 심법의 획득 경로(사승·유품·기연·깨달음) → 핵심 심법 운용 → 내공 축적/성질/안정 → 초식·보법·병장기·진법 → 비기·경지 돌파.

- 핵심 심법은 **활성 슬롯 1개**. 다른 심공의 구결 소지·학습 기록과 활성 운기를 분리.
- 심법 품질, 숙련도, 내공 총량, 무학 전문성, 레벨, 무협 경지는 **각각 독립 상태**.
- 27 Point Buy의 여섯 능력치와 선천 재능은 별개. 괴물·초월을 STR/INT 가산으로만 표현하면 안 된다.
- 정파·사파·마교의 도덕적 평가는 각 인물·행동으로 판단. 이름만으로 NPC 전원이 선악을 안다고 가정하지 않는다.
- 무공과 마법은 동일 근원을 쓰는 서로 다른 수련 방법(D-011·D-021), 무협 중심 개편은 마법 삭제가 아님.

## 2. 재능의 실효적 특혜 [STRUCTURE CONFIRMED / TABLE PROPOSED]

기존 v10 2차 문서의 서열: **범재 < 수재 < 천재 < 괴물 < 초월**.
사용자 표현 **비범**은 당분간 천재 수준을 설명하는 별칭 후보. 별도 6등급 여부 OPEN.

**확정 방향:** 문파 입교 시 고재능은 사부 지도/비전 심법 접근/초기 심공 수련에서 실질적 특혜를 받는다. 무문파 고재능도 초반부터 이에 상응하는 기연·유산·깨달음을 통해 좋은 심법에 접근할 **보장된 시작 경로**를 갖는다. 범재도 최상위 경지 도전 기회를 잃지 않는다.

| 재능 | 문파 입교 시작안 [PROPOSED] | 무문파 시작안 [PROPOSED] |
|---|---|---|
| 범재 | 기초 심법 온전 전수·기초 지도 | 안정적 기초 토납법 및 유능한 기연 탐색 경로 |
| 수재 | 정통 심법 지도·빠른 인정 | 정통 구결 또는 독학 선생 인연 |
| 천재(비범) | 정통 심법 즉시 수련·상급 심법 시험 기회 | 정통 심법+상급 비급 일부 해독 단서 |
| 괴물 | **상급 심법 입문 전수 보장**, 비전 후보/장로 지도 | **상급 심공에 들어갈 수 있는 기연 보장**, 결손된 구결의 이해 |
| 초월 | **비전 심법의 첫 운기 관문 보장**, 절세 후보·후계 시련 | **비전급의 정당한 유산·기연과 첫 운기 관문 보장**, 고유 깨달음 사건 |

- 위 표는 숫자·정확한 품질 등급 배정이 승인되지 않은 **강한 상세 추천안**. 고재능의 *실제 전수 차별* 자체는 구조적으로 확정.
- 심법 구결 접근(access), 전수(teaching), 실습(activation), 숙련(mastery), 공력(accumulation)은 다섯 단계다. 입문 즉시 대성/절정 경지 자동 부여 금지.
- 고재능 특혜를 단순 확률상 우대만으로 축소하지 않는다. 첫 장에서 관찰되는 기술 선택·지도/구결·문파 반응의 차이가 반드시 있어야 한다.
- 재능의 획득 방식(직접 선택/설정형/랜덤/서사 시험)은 OPEN. 캐릭터 기존 세이브에 임의 재능 배정 금지.

## 3. 심법 데이터 모델 [STRUCTURE CONFIRMED, FIELD NAMES PROPOSED]

- scriptureId, provenance(사문/은거고수/기연/독학), owner, teacher, teachingPermission
- accessStatus(인지/접근/전수/소지/운용), textCompleteness(일부/완전), quality
- masteryStage(구결 소지/입문/소성/대성/원만), insights, innerPowerReserve
- nature(정순/강맹/음한/유전/환류/잠행/양생/진식 등의 후보)
- circulation, stability, incompatibleArts, prerequisites, learnableSecrets, consequences
- activeHeartArtId: **동시에 하나**. 새 심법을 입수했다고 즉시 핵심 슬롯 자동 교체 금지.

심법 품질 단계 제안: **기초 → 정통 → 상급 → 비전 → 절세**.
수련 단계 제안: **미운용(구결만 소지) → 입문 → 소성 → 대성 → 원만**.
품질이 높다고 명중·자원·HP·방어를 무조건 전부 상승시키는 보너스는 금지. 각 심법은 장점·상성·수련 비용·부담·완전성의 다차원 구조를 가진다.

## 4. 심법 종류별 개성 [ORIGINAL EXAMPLES, ALL PROPOSED]

| 임시 심법 이름 | 성질·장점 | 약점 또는 숙련 한계 | 최초 출처 후보 |
|---|---|---|---|
| 유천호흡법 | 정순, 안정적 토납·범용 외공 | 한순간 출력·특수 기운 운용에는 준비 필요 | 무문파·기초 교습 |
| 연화정심결 | 양생·정순, 호위·회복 기반 | 강맹 기술과 즉시 혼용이 어려움 | 정파의 사승 |
| 태허유전법 | 유전·반격, 상대 기운을 흘림 | 기운을 읽기 어려운 교란에 취약 | 유검·유권 문파 |
| 청해한맥공 | 음한, 빙공·극한 수련의 강점 | 기혈 제어를 잃으면 부작용 | 북해 계통 |
| 흑뢰흡원공 | 강맹·환류, 짧은 시간 힘을 변환 | 축기/기혈 기초가 부족하면 출력 제한 | 천마신교 고위 수련 |
| 만상귀류심공 | 혼합·환류, 독행자의 구결 통합 | 상충 심법·불완전 구결 위험 | 기연·독학 |

이 이름들은 특정 출판 작품의 명칭을 복제하지 않고 임시로 만든 창작 후보이며, 공개 배포 전 이름 중복·유사성 검토가 필요하다.

## 5. 심법의 실제 획득 트랜잭션

1. 구결·스승·비급의 존재를 플레이어가 발견했는가?
2. 전수 또는 획득의 합법적 출처와 실제 NPC의 지식·권한이 있는가?
3. 입문 조건(재능·체질·오성·인연·시련·전승)을 충족했는가?
4. 훈련 시간/위험/공헌 등 공개된 조건을 실제로 치렀는가?
5. 구결 보유와 심법 활성·숙련 상승을 구분하여 선택받았는가?
6. 핵심 심법 슬롯 1개와 기존 수련 이력을 보존했는가?
7. 전후 수치·세계 시간·사부 관계·잔맥 부작용을 기록했는가?

불합법 행동에 주사위·시간·자원을 소비하지 않는다. 실패해도 시련의 후속 사건을 기록하며 무한 재시도 보상은 금지한다.

## 6. 무공과 무학 전문화

검법/권법/도법/활/독·암기/빙공/진법/경공/술법 등은 **사문과 독립된 무학 분야**이며 하나의 캐릭터가 여러 분야를 익힐 수 있다.
옛 5직업은 **압박·연계 / 유도·반격 / 기동·교란 / 정밀·견제 / 축적·변환** 태그로만 사용하며 강제 직업 수·사문 수가 아니다.
같은 심법을 두 사람이 익혀도 검결·권장·진법과의 상성이 다르므로 무공과 전술·비전투 수련이 달라진다.

## 7. 기존 v10 경계

- STR/DEX/CON/INT/WIS/CHA + 27 Point Buy 유지.
- Lv.1 핵심 심법1 + 액티브2 + 추가행동1 + 반응1 + 일반 패시브3 + 고유재능2 = **10개 유지**.
- Lv.1~12 누적 XP 및 레벨별 보상 유형 유지; Lv.10 심법 진화는 별도 보상이고 경지 자동 돌파가 아님.
- d20, 자연 1/20, 행동권, HP/MP/SP와 크림이 자율 동료 구조 유지.
- **세부 내공 양·수련시간 공식, 기연 빈도, 재능별 수치·심법 품질 부여, 주화입마 확률, MP/SP와 내공의 관계는 OPEN.**

## 8. 재능·심법·문파 시작의 검증

- Lv.1 세 재능(범재/괴물/초월) × 두 시작(문파/독행)을 모두 구현·비교한다.
- 상위 재능은 첫 장부터 실제 구결·사부 대사·심공 전수·깨달음 선택지에 차이가 있어야 한다.
- 기초 심법 대성자 vs 비전 심법 입문자는 일괄 우열로 처리하지 않는다.
- 무문파도 정규 성장 보상과 10슬롯을 빼앗기지 않는다.
- 다른 문파에 입단하거나 파문당해도 과거 수련과 인연이 사라지지 않는다.
- 현재 REBIRTH Lv.2 세이브는 종족·재능·직업·심법이 빈 상태: **선택 전에 어떤 심법도 소급 전수하지 않음.**
